# Changelog

All notable changes to OAEM will be documented in this file.

The format is inspired by Keep a Changelog and follows a pragmatic versioned history suitable for methodology evolution.

## [0.1.0] - Foundation

### Added
- Initial OAEM public foundation documents.
- Mission, positioning, and scope boundaries.
- Origin and practical motivation, including recurring failure modes.
- Initial adaptive depth model (Levels 0-3).
- Core loop framing: intent → classify → choose depth → shape work → execute → verify → checkpoint → decide → learn.
- Language policy (English canonical + pt-BR first-class translation).
- Roadmap without delivery dates.
- Initial governance and security boundary principles.
- Foundational repository structure for methodology, adapters, templates, skills, conformance, and examples.
- OAEM visual banner (SVG).

### Notes
- OAEM v0.1 is experimental and intended for iterative refinement through real usage and conformance evidence.
