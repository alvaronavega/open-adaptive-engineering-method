# Third-Party Notices

This repository currently does not bundle third-party source code.

OAEM acknowledges conceptual inspirations from public work in the AI-assisted engineering ecosystem.

## Acknowledged inspirations

### GitHub Spec Kit
OAEM draws inspiration from the value of explicit intent, structured planning, traceable artifacts, and quality-oriented workflow gates that can support portability across agents.

### Skills for Real Engineers (Matt Pocock)
OAEM draws inspiration from the value of small composable Skills, practical engineering workflows, vertical slicing, TDD-oriented behavior, and iterative diagnostics.

## Clarifications

- OAEM is **not** a fork of GitHub Spec Kit.
- OAEM is **not** a fork of Skills for Real Engineers.
- OAEM does **not** claim endorsement by those projects or their authors.
- OAEM does **not** claim to replace either project.

OAEM emerged from practical long-running engineering experience combining strengths from specification-driven and skill-driven approaches, while addressing governance, evidence, completion, and portability gaps observed in real workflows.
