# Skills Directory

## Purpose

This directory is reserved for OAEM-aligned engineering Skills that operationalize methodology behaviors.

Skills support OAEM, but they do not define OAEM core principles by themselves.

## What belongs here

- reusable, composable workflow Skills aligned with OAEM contracts;
- Skills for classification, slicing, verification, checkpointing, and review;
- Skill documentation that references OAEM method contracts and boundaries.

## What does not belong here

- project-specific private prompts mixed as canonical OAEM assets;
- harness-specific runtime internals (these belong in adapters);
- copied third-party skill packs without explicit governance fit.

## Adoption focus for existing repositories

- `assess-project`: build evidence-grounded project understanding in read-only mode before consequential changes.
- `adopt-oaem`: incrementally introduce OAEM by integrating with existing practices first.
- `reorganize-existing-project`: classify and simplify project structure safely with vertical, checkpointed slices.
