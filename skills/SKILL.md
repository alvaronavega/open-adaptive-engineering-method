# OAEM Skill Contract

## Purpose

Define the minimalist common contract for OAEM Skills that ensures integration, adaptability, and clarity.

## Core Contract Elements

1. **Execution Context**
   - Declare when the Skill runs
   - Specify prerequisites
   - Identify when it should not run

2. **Inputs and Context**
   - Define necessary inputs
   - Clarify context dependencies

3. **Outcome Expectations**
   - State expected outcomes
   - Highlight completion evidence

4. **Autonomy and Boundaries**
   - Define when it may continue autonomously
   - Identify human boundaries

5. **Next Steps**
   - Suggest subsequent Skills or states

## Contract Characteristics

- Model-agnostic
- Harness-agnostic
- Project-agnostic
- Composable
- Vertically oriented
