# Examples Directory

## Purpose

This directory is reserved for OAEM reference workflows and illustrative examples that show practical method usage patterns.

Examples should make methodology behavior concrete without redefining OAEM core.

## What belongs here

- example flows showing adaptive depth selection;
- vertical-slice implementation examples (future);
- evidence and checkpoint reporting examples (future);
- cross-harness usage examples once adapters mature.

## What does not belong here

- production project source code presented as OAEM canonical;
- copied third-party demos without governance context;
- harness-specific implementation internals that belong in adapters.

## v0.1 maturity

Foundation v0.1 does not ship full runnable examples yet.

At this stage, OAEM establishes documentation architecture and method contracts first.

## Future direction

Planned examples should prioritize:
- existing-project OAEM adoption patterns;
- defect-resolution vertical slices;
- completion/evidence reporting clarity;
- cross-machine reproducibility scenarios;
- conformance-oriented example validation.
