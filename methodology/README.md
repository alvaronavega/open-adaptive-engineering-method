# Methodology Directory

## Purpose

This directory contains OAEM core methodology artifacts and contracts as they mature beyond foundation-level narrative documentation.

## What belongs here

- core methodology contracts (future versions);
- canonical method-level schemas when stabilized;
- normative definitions for completion, evidence, checkpoints, and learning loops;
- method evolution/versioning notes that affect OAEM core behavior.

## What does not belong here

- harness-specific adapter implementation details;
- project-specific workflow scripts;
- one-off experimental notes with no method relevance;
- generated artifacts that are not canonical source.

## v0.1 maturity

At v0.1 (foundation), OAEM is primarily documentation-first.  
Method core is defined in `docs/en/**` with mirrored pt-BR translation in `docs/pt-BR/**`.

This directory remains intentionally lean until core contracts are formalized.

## Future direction

Planned evolution includes:
- explicit completion/evidence/checkpoint contract definitions;
- portable conformance-oriented method assets;
- stable method versioning toward OAEM 1.0.
