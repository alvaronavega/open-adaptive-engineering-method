# Templates Directory

## Purpose

This directory is reserved for OAEM template assets that help teams apply adaptive methodology depth with consistent structure.

Templates are supporting artifacts for OAEM usage, not substitutes for method judgment.

## What belongs here

- template structures for adaptive-depth artifacts;
- ticket/spec/decision/evidence/checkpoint template scaffolds;
- traceability-friendly formats for completion and review.

## What does not belong here

- mandatory one-size-fits-all process documents;
- project-specific implementation playbooks treated as OAEM canonical;
- generated files without source-maintained template intent.

## v0.1 maturity

Foundation v0.1 does not ship a full template suite yet.  
Template responsibilities are defined now; concrete template sets are planned for upcoming versions.

## Future direction

Expected template families include:
- Level 1 ticket and acceptance templates;
- Level 2 temporary specification and vertical story templates;
- Level 3 governed-change decision and risk templates;
- completion/evidence/checkpoint reporting templates.

Templates should reduce ambiguity while preserving adaptive, minimum-sufficient usage.
